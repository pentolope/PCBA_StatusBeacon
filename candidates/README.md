# Candidates

Disposable. Everything in this directory except this file is ignored by Git.

Placement and routing search produces far more boards than it keeps. A candidate
here is a **comparison artefact**, not a design: it has no authority, it is not
the board, and nothing about it is true because it exists. Rejected runs are
deleted rather than archived — an unpromoted pool costs clone time and buys
nothing, and this repository is one of thirty-two.

A candidate leaves this directory only by an explicit human promotion, which
moves it somewhere it is named, explained and bound to the run that produced it.
Copper is never edited on the way.
